# 🐍 JavaFX Snake Game with MySQL Leaderboard

This project is a desktop-based Snake Game developed using JavaFX. It features smooth gameplay, collision detection, and a MySQL-integrated leaderboard system to store and display high scores.

---

## 🚀 Features

- 🎮 Interactive Snake Game with smooth controls  
- 💥 Collision detection (walls & self)  
- 📈 Real-time score tracking  
- 🗄️ MySQL database integration  
- 🏆 Leaderboard system with persistent high scores  
- 🎨 JavaFX-based graphical user interface  

---

## 🛠️ Technologies Used

- Java  
- JavaFX  
- MySQL  
- JDBC (Java Database Connectivity)  

---

## 📊 How It Works

- The snake moves continuously based on user input  
- Game ends when the snake collides with walls or itself  
- Score increases as the snake eats food  
- Final score is stored in MySQL database  
- Leaderboard fetches and displays top scores dynamically  

---

## ▶️ How to Run

1. Clone the repository  
2. Open the project in IntelliJ / Ellipse 
3. Connect MySQL database  
4. Update database credentials in the code  
5. Run the main Java file
